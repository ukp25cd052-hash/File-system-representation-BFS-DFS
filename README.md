##Project Description

This project demonstrates file system representation using a graph data structure. It uses Breadth First Search (BFS) and Depth First Search (DFS) algorithms to traverse the graph and search for files or directories.

##Objectives

- To represent a file system using a graph.
- To understand BFS and DFS algorithms.
- To traverse the graph efficiently.
- To search for files and directories.

 ##Technologies Used

- C Programming Language
- Graph Data Structure
- BFS (Breadth First Search)
- DFS (Depth First Search)

 ##Features

 -Represents files and directories as a graph.
 -Supports BFS traversal.
 -Supports DFS traversal.
 -Searches for a target file or directory.
 -Displays the traversal results.

 ##How It Works

1. The user enters the file system details.
2. The program represents the details using a graph.
3. The user selects BFS or DFS traversal.
4. The program searches the graph.
5. The traversal results are displayed.

##Conclusion

This project helps us understand graph representation and traversal using BFS and DFS algorithms. It demonstrates how graph traversal can be used to search and explore a file system.
